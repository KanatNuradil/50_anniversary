# Мейірбек — 50 жас мерейтойына шақыру

## Іске қосу
1. ZIP архивін ашыңыз.
2. `index.html` файлын Chrome немесе Edge браузерінде ашыңыз.
3. Бастапқы анимация автоматты түрде жүреді. Қаласаңыз, «Шақыруды ашу» батырмасын басып өткізіп жіберуге болады.

## Фото
Шақыру ішіндегі «Суретті жүктеу» батырмасын басып, әкеңіздің бала кездегі фотосуретін таңдаңыз.

## Музыка
Жоғарғы оң жақтағы «Музыка» батырмасын басып, компьютерден MP3 немесе басқа аудио файлды таңдаңыз. Кейін сол батырмамен музыканы тоқтатып/қоса аласыз.
Браузерлер дыбысты автоматты ойнатуға шектеу қояды, сондықтан музыка пайдаланушы әрекетінен кейін қосылады.

## RSVP
Қазіргі нұсқада форма тек браузер ішінде растау хабарламасын көрсетеді. Жауаптарды нақты жинау үшін Google Sheets / Apps Script немесе backend қосу қажет.

## Файлдар
- `index.html` — сайт құрылымы және шақыру мәтіні
- `styles.css` — дизайн және анимациялар
- `script.js` — 50 есік, фото, музыка, RSVP және бөлшектер анимациясы

Күн мен жыл мәтінінде тек «27 желтоқсан» көрсетілген. Қажет болса, жылын HTML ішіндегі тиісті мәтінге өзіңіз қосыңыз.
